# 八、交付计划与验收（一）：关键操作的成功与失败状态

本篇是排期与验收的依据。每个阶段都给出交付范围、用户闭环与必须覆盖的失败路径。

> **本文档属于排期层**。下表是验收时逐行核对的清单：每个操作都必须能在实现中明确区分「成功提交」「可重试」「终态失败」三种结果。

---

## 42. 关键操作的成功与失败状态

| 操作 | 成功提交的最小条件 | 可重试情况 | 终态失败 |
|---|---|---|---|
| 创建组织 | 创建者账号有效；组织名通过校验；组织、所有者成员记录和审计事件在同一事务提交 | 网络超时后按幂等键查询 | 名称不合法、账号冻结、配额不足 |
| 恢复自建组织账号 | 恢复包加口令或守护人阈值通过；新设备密钥注册；旧设备冻结 | 守护人暂时离线、邮件/第二验证服务短暂失败 | 恢复证明无效、阈值不足、组织恢复包缺失、风险策略拒绝 |
| 邀请成员 | 邀请者有成员管理权；目标可被邀请；邀请记录和通知提交 | 通知或在线推送失败 | 无权限、目标已移除、邀请码过期、组织已挂起 |
| 切换组织 | 账号是目标组织有效成员；组织策略和权限快照已加载 | host 缓存同步短暂失败 | 成员无效、组织挂起、凭证过期 |
| 更新在线状态 | 已认证设备心跳通过；状态可见范围符合个人设置 | 网络短暂失败，下一次心跳重试 | 设备撤销、账号冻结、签名无效 |
| 建立长连接 | TLS/relay 指纹、设备会话、组织权限和连接额度均通过 | 服务器平滑重启、网络中断后补拉 | 指纹不匹配、设备受控、组织挂起、连接超额 |
| 处理异常地点风险 | 用户/管理员以受信任设备或第二验证因素通过挑战；风险事件完成审计 | 验证服务暂时不可用 | 挑战过期、证明无效、管理员拒绝、设备已暂停 |
| 邮件停止异地设备 | 邮箱链接有效，用户已重新认证；目标设备属于该账号且未撤销 | 邮件投递失败时在已授权设备的安全中心处理 | 邮箱未验证、链接过期、认证失败、目标设备已撤销 |
| 分派工作项 | 操作者有分派权；负责人是有效项目成员；版本匹配 | 超时后查询同一命令结果 | 版本冲突、负责人无项目权限、工作项终态 |
| 签收工作项 | 负责人有效且签收状态为 `offered`；确认理由与版本提交 | 网络超时后按幂等键查询 | 工作项已取消、负责人已变更、签收已过期 |
| 提交评审结论 | 评审人有项目读取权且非提交者；关联产物版本未变化；结论与审计提交 | 网络超时后按幂等键查询 | 产物已变化转 `superseded`、评审已过期、评审人无资格 |
| 接受候选产物 | 确认者有目标资源写权限；版本比较通过；新版本、归因与通知同事务提交 | 超时后按幂等键查询 | 版本冲突、协作会话已撤销、权限被收回 |
| 发送消息 | 发送者与目标均通过策略；私聊队列或群日志配额可用；消息与对应队列/群日志记录提交 | 网络超时、租约重投、ACK 或群游标补拉 | 无权限、被拉黑、队列满、群日志配额耗尽、组织挂起、输入超限 |
| 发布共享对象 | 共享者可读原对象；目标有效；ACL、共享记录、审计和通知提交 | 超时后按幂等键查询 | 资源已删除、目标无资格、版本冲突、访问级别超权 |
| 上传资源 | 上传预约与摘要匹配；上传者有目录写权；版本记录提交 | 分块网络失败、扫描器短暂不可用 | 配额不足、摘要不符、文件类型拒绝、恶意文件、预约过期 |
| 授予群历史 | 群管理员选择固定游标/时间范围；接收人有效；消息、附件和资源授权原子提交 | 通知失败或接收方离线 | 无权限、范围超出策略、E2E 旧 epoch 不可用、资源禁止快照 |
| 发送共享资源快照 | 资源版本可用且目录策略允许；`MessageContentGrant` 与消息原子提交 | 上传/下载短暂失败 | 资源已删除、快照被禁止、目标无资格、配额不足 |
| 绑定项目群仓库 | 操作者有项目群管理权；仓库 URL、提供方和访问模式通过策略 | 远端验证或 webhook 注册暂时失败 | URL 不允许、重复绑定、无权限、仓库认证失败 |
| 记录 AI 辅助提交 | hash 与绑定仓库匹配，且 webhook/API 验证作者和提交存在 | 远端暂时不可访问时继续验证 | hash 不存在、签名无效、作者冲突、仓库已撤销 |
| 继续协作会话 | 成员有 `continue` 权限；输入快照有效；可写资源租约可取得或已建分支 | 执行 host 短暂离线、可恢复工具失败 | 会话撤销、工作项关闭、版本冲突、权限被收回 |
| 启动沙箱执行 | `ExecutionProvider` 可用；能力、预算、仓库/资源版本和确认挑战通过 | provider 暂时不可用、可恢复镜像拉取失败 | 沙箱配额不足、网络/秘密/命令未授权、项目或仓库权限失效 |
| 调用公共 Bot | 调用者、群/项目、Bot 和策略全部有效；上下文快照在额度内 | Bot host 或模型短暂故障 | 无调用权、上下文超限、Bot 已移除、工具策略拒绝 |
| 发布公共插件 | 审核人有权限；精确版本、权限清单和审核记录已提交 | 签名或漏洞扫描服务短暂不可用 | 审核拒绝、签名不符、依赖不允许、套餐不支持 |
| 生成周报/月报 | 调用者有分析权限；数据时间窗、范围和报告模板有效 | 分析聚合尚未完成 | 数据范围无权限、样本不足、组织禁用报告 |
| 计算同层级排行 | 比较组、样本量、角色族和工作项归属均有效 | 聚合任务短暂失败、数据更正后重算 | 样本不足、跨角色比较、复杂度未确认、组织已关闭排行 |
| 端到端密钥轮换 | 所有有效设备已获取并验证新 epoch；成员变更和审计事件已提交 | 离线设备稍后补取密钥包 | 指纹未确认、设备撤销、成员权限失效、密钥包校验失败 |
| 登记第二验证因素 | 确认挑战与已授权设备确认通过；当场完成一次验证；备用码已签发并只保存哈希 | 认证器时钟偏移在容忍窗口内重试 | 挑战过期、验证失败、组织禁用该因素类型、删除后不满足强制策略 |
| 转让组织所有权 | 发起方与接收方均通过确认挑战和第二因素；接收方为 `active` 组织管理员；角色变更、审计与通知同事务提交 | 接收方暂未确认时保持待处理 | 接收方无资格、组织挂起、发起方非所有者、公示期被中止 |
| 执行搜索 | 调用者成员状态有效；查询在复杂度与速率上限内；候选结果逐条通过 ACL 复检 | 索引滞后时提示结果可能不完整并可重试 | 无成员资格、组织挂起、跨组织查询、E2E 模式下请求服务端正文检索 |
| 请求数据导出 | 请求者权限已按对象逐条裁剪；导出包加密并绑定请求者；生成与审计提交 | 打包或对象存储短暂失败 | 无权限、超出导出配额、组织挂起、法律保留冲突 |
| 注销账号 | 重新认证与确认挑战通过；无唯一所有者、账单、法律保留等阻塞；进入宽限期 | 宽限期内可由本人撤销 | 仍是唯一组织所有者、存在未结算账单或法律保留 |
| 删除组织 | 所有者确认挑战与双人确认通过；组织转只读并进入宽限期；全员通知已提交 | 宽限期内可撤销 | 非所有者、存在法律保留、订阅未结清、确认过期 |

**任何操作在返回成功前都已经写入持久化状态；返回超时不代表失败，客户端必须查询同一幂等键的结果。**

**任何操作在返回失败前都必须说明能否安全重试。浏览器不能把“未收到响应”直接渲染为失败后重新生成 ID 再次提交。**

> 错误码与可重试性的权威定义，见[契约与规范附录 §46 错误码目录](../03-details/06-contracts-and-conventions.md#46-错误码目录)。
