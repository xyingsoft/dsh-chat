## 一、现状：已有的展示与交互

### 1.1 设置面板（`StatusSection`）
- ✅ dsh-chat 分区已注册，展示**能力状态表**：插件装载、错误码集合、本地持久化、授权判定等模块状态（已就绪绿 / 部分实现橙 / 未装载灰）
- ✅ 头部显示「协议版本 v1 · 数据库 schema v1」
- ✅ 「打开配置文件」「导出诊断信息」「打开 DSH 终端」三个按钮（DSH 原生按钮，非本插件实现）

### 1.2 会话页右侧抽屉（`ChatDrawer` + `ChatSection`）
- ✅ 会话头部「聊天」按钮，未读角标，点击右侧滑出抽屉（默认 520px，可拖 300–900px）
- ✅ 抽屉头部：标题、可见范围选择器（`VisibilityPicker`）、恢复默认宽度、关闭
- ✅ 布局：≥640px 并排（左列表 + 右消息），<640px 单栏钻取（列表 → 消息 + 返回条）
- ✅ Tab 切换：「会话」/「通讯录」两栏

#### 1.2.1 会话列表（`ConversationList`）
- ✅ 会话条目：在线状态点（实/空/无，配 `title`/`aria-label`）、名字、预览、时间、未读角标（>99 折 99+）
- ✅ 选中高亮、空态文案「还没有会话」
- ⚠️ 只渲染 host 返回的数据，**时间格式只取 MM-DD HH:MM，无「今天/昨天」等相对时间**

#### 1.2.2 消息视图（`MessageView`）
- ✅ 左右分侧气泡，作者名 + 时间
- ✅ 撤回占位「[已撤回]」、已编辑标「已编辑」（撤回的不重复标已编辑）
- ✅ 本端发送的消息显示投递态：待发送 / 服务器已接收 / 发送失败（失败给重试按钮）
- ✅ 事件流状态条：已连接（不显示）/ 正在重连 / 连接已断开 / 同步分叉（停止自动重发）
- ✅ 失败重试按钮只对 retryable 错误出现
- ✅ 空态「还没有消息」
- ❌ **没有头像**（连占位都没有）
- ❌ **没有上下文菜单**（长按/右键菜单：复制、编辑、撤回、转发、回复、引用、删除…）
- ❌ **没有消息操作入口**（编辑/撤回只能经 API，界面无入口）
- ❌ **没有已读/已送达回执**（P0 文档明确不做，但界面没有任何对应告知）
- ❌ 纯文本，不支持 @ 提及、表情反应、引用、附件、代码块

#### 1.2.3 输入框（`Composer`）
- ✅ Enter 发送 / Shift+Enter 换行，输入法组合期间不发送（`isComposing`）
- ✅ 字数按字素簇计（`Intl.Segmenter`），上限 8000，剩余 ≤200 显示计数，超限时变红
- ✅ 发送先清空输入框，失败回滚并显示错误；发送中按钮变「…」
- ✅ 发送失败错误由 `presentError` 给出文案
- ❌ **没有草稿保存**（关掉抽屉再开，未发送内容丢失）
- ❌ **没有 @提及、表情选择、附件上传按钮**
- ❌ **没有粘贴/拖拽文件**入口
- ❌ **多行高度不自适应**（固定 1 行 rows=1，多行会有滚动条但不会撑高）
- ❌ 发送失败的消息**点击重试未接通**（`onRetry` 由 props 传入，`ChatSection` 里没传）

#### 1.2.4 通讯录（`DirectoryPanel`）
- ✅ 搜索框，按名字过滤
- ✅ 待处理请求置顶（「待处理请求（N）」+ 接受按钮）
- ✅ 四种状态按钮：发消息 / 等待通过（禁用）/ 在上方待处理 / 加联系人
- ✅ 空态：「这个组织里还没有别人」/「没有匹配的同事」
- ❌ **没有拒绝按钮**（API 有 `/contacts/reject`，界面未接）
- ❌ **没有移除联系人入口**（API 有 `/contacts/remove`，界面未接）
- ❌ **没有组织/工作区/项目三级结构**（现在是扁平成员列表）
- ❌ 自己不在列表里，但没有「我的资料」入口

#### 1.2.5 开户面板（`EnrollmentPanel`）
- ✅ 邀请码、显示名、设备名三字段，设备名按平台猜默认值
- ✅ 三字段非空才能提交，提交中禁用按钮，输入即清上次错误
- ✅ 失败只显示「这张邀请码无法使用」（不区分已过期/已消费/不存在）
- ❌ **没有登录/退出/设备切换界面**
- ❌ **没有「已开户」后的账号信息页**（我的 ID、设备列表、退出登录）

## 二、🔴 P0-b 必须补齐的 UI（文档明确要求）

| 模块 | 需补内容 | 文档出处 |
|---|---|---|
| **第二因素 (2FA)** | 设置里加「账号安全」分区：TOTP 二维码/密钥展示、6 位验证码输入、备用码展示（一次性，复制后警告）、已登记设备列表、撤销入口 | §8.1 步骤 1–2；P0-b 要求未登记 2FA 时**只能访问账号安全设置**，其余入口需锁定 |
| **组织强制策略提示** | 未满足策略时（未登记 2FA、密码强度、版本不兼容）在抽屉顶部给出**占据布局的警告条**（不是 toast），指向解决入口 | §8.1 步骤 2；presentError 已有 `conditional` 状态，但界面未渲染前置条件入口 |
| **恢复 (RecoveryKit)** | 账号安全里：生成恢复包按钮 → 展示守护人拆分方案 → 下载/保存引导 → 「我已保存」确认；恢复流程入口（从其他设备/新设备登录时触发） | §8.1 步骤 3 |
| **在线可见范围** | 抽屉头部的 `VisibilityPicker` 目前**只有 UI 壳，未接通 API**（`/presence/visibility/set` 路由已注册但 `VisibilityPicker` 没调）；需：在线/空闲/离线/对谁可见四档选择，切换即时保存 | §8.1 步骤 4；`presence-commands.ts` 有 visibility 路由 |
| **本地搜索** | 会话列表上方加搜索框（注意：与通讯录搜索是两个搜索，不要混）：按消息正文/联系人名搜本地缓存，结果高亮关键字，撤回的消息不出现在结果中 | §8.1 步骤 5 |
| **协议协商失败态** | 当 `PROTOCOL_VERSION_UNSUPPORTED` 时，抽屉替换为升级提示页（不是一个小 banner），告知版本不兼容、提供升级指引 | §8.1 步骤 6 |
| **发送失败重试接通** | `MessageView` 的 `onRetry` 接到 `ChatSection`，点击重试能重发 pending/failed 消息 | 代码 TODO：`onRetry` 已在 props 但从未传入 |

## 三、🟠 P1 阶段 UI（群聊、资源库、附件、服务端搜索）

| 模块 | 需补内容 |

| **消息操作** | 右键/长按菜单：复制、编辑（本人 10 分钟内）、撤回、引用、转发、回复、删除（本地删除 vs 撤回）、多选 |

| **资源库** | 新增 Tab 或独立分区：文件/文档列表、按项目/会话聚合、上传入口、预览（图片直显，其它给图标）、权限继承显示 |

| **工作项 UI**（目前只有 API，没有界面） | 工作项列表（指派给我/我创建/全部）、详情页（状态、截止时间、依赖关系、评审关口）、评论、状态流转按钮 |
| **通知中心**（目前只有 API，没有界面） | 通知收件箱独立入口、按类型分组（工作项/邀请/审核/系统）、聚合显示、全部已读、跳转到对应上下文 |
| **多设备/跨主机界面** | 设备列表（我的设备/活跃设备）、远程下线、设备名称编辑、新设备登录告警条 |
| **头像** | 生成式头像（首字+颜色）、头像上传入口、群头像 |
| **相对时间** | 「刚刚 / X 分钟前 / 今天 HH:MM / 昨天 / MM-DD / YYYY-MM-DD」，跨时区显示时区标识 |
| **会话列表聚合端点 UI 对齐** | host 补 `/conversations` 聚合查询后，列表字段（lastMessage 类型、草稿、pin、mute）需对应呈现 |

## 四、🟡 P2 阶段 UI（协作会话、沙箱执行、Bot、线程与转发）

| 模块 | 需补内容 |
|---|---|
| **协作会话** | 会话里能看到 AI 协作入口：选中上下文 → 发起协作 → 候选产物卡片（采纳/拒绝/编辑）→ 采纳后插入消息 |
| **沙箱执行 UI** | 命令执行的输出流展示（不是静态块）、终止按钮、产物区、权限提示 |

| **转发** | 转发目标选择器（搜索联系人/群）、转发附言、转发引用样式（原消息卡片+转发者） |
| **表情反应** | 消息下方反应条、常用表情、hover 显示谁点了什么 |
| **草稿** | 每个会话独立草稿（localStorage 或 host 存），切换会话不丢，草稿在列表预览显示 |

| **输入中状态** | 对方正在输入时在会话列表和消息区显示「XX 正在输入…」 |

## 七、🔧 全局/基础设施类 UI 缺口（不绑阶段，但越早补越好）

| 类别 | 缺口 |
|---|---|
| **空状态/加载/错误态** | 目前 5 个主要面板（会话、消息、通讯录、开户、状态）有，但：工作项、通知、搜索、资源、设置子页都没有；错误文案统一走 `presentError` 但 `conditional` 类错误没渲染「解决入口」按钮 |
| **可达性 (a11y)** | 现有组件已带 `role`/`aria-*`，但缺：焦点环样式、键盘导航（↑↓ 选会话、Esc 关抽屉已有，Tab 顺序未走查、焦点陷阱在抽屉里没有）、屏幕阅读器实测、颜色对比度校验 |
| **暗色模式** | DSH 支持暗色主题，当前 CSS Modules 未做暗色适配（颜色全部硬编码） |
| **国际化** | 全部文案硬编码中文，无 i18n 框架；README 有英文版但 UI 没有 |
| **loading 骨架** | 目前 loading 态只显示一行「正在加载…」，没有骨架屏，慢网下跳变明显 |
| **toast/通知系统** | 操作成功/失败无 toast（发送失败在输入框下方显示，但其他操作如「加联系人请求已发送」没有反馈） |
| **快捷键** | 除了 Esc 关抽屉、Enter 发送，没有其他全局/局部快捷键（Ctrl+N 新会话、Ctrl+K 搜索、↑编辑上一条…） |
| **右键菜单组件** | 无通用 Dropdown/Menu 组件，所有消息操作都需要这个基础设施 |
| **对话框组件** | 无通用 Modal/Dialog 组件（确认撤回、确认删除、TOTP 登记都需要） |
| **虚拟滚动** | 消息列表与会话列表现在全量渲染，群聊/长历史下会卡（P1 前必须补） |
| **图片/文件预览组件** | 目前纯文本，附件到位前需要通用预览组件（图片 lightbox、视频 player、文件下载卡） |

## 八、📋 建议落地顺序（视觉→交互→功能的合理切片）

**第一批：把 P0-b 的 UI 壳子先搭起来**（因为后端 P0-b 还没写，前端可以先做静态壳）
1. 账号安全分区骨架（2FA、RecoveryKit 入口的位置与跳转）
2. VisibilityPicker 接通 `/presence/visibility/set`（API 已有）
3. 本地搜索框 UI（host 索引未做，但输入框+过滤客户端消息可先做）
4. 发送失败重试接通 `onRetry`
5. 通用组件：Dialog、Toast、DropdownMenu（为后续做准备）

**第二批：补体验缺陷**
6. 头像（生成式）、相对时间
7. 草稿保存（localStorage 即可）
8. Composer 自适应高度
9. 消息右键菜单：复制、编辑、撤回
10. 拒绝/移除联系人按钮

**第三批：P1 大项**
11. 附件上传 + 预览
12. 工作项 UI、通知中心 UI
13. 群聊类型会话 + @提及
14. 服务端搜索
