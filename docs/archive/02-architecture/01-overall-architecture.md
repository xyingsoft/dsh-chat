# 二、架构与插件模型（上）：三层总体架构

本篇定义组件边界与扩展模型。核心原则是凭证按层隔离、能力按插件拆分，且不存在特权内核。

> **本文档属于架构层**。它把[需求层](../01-requirements/01-positioning-and-boundaries.md)的边界声明落到组件切分上；细节层的所有机制都必须落在此处定义的层内，不得跨层直连。

## 4. 三层总体架构

**浏览器只负责呈现和交互，不持有组织秘密、relay 凭证或设备私钥。**

DSH host 负责本地持久化缓存、保存设备凭证、运行 relay 客户端、发送在线心跳、安排重试，并提供浏览器使用的同源 API。

relay 是组织协作的权威运行面，由 dsh-chat 插件组合而成。身份、组织、成员、消息、资源、通知、仓库、协作执行、Bot、插件目录、分析和计费各自拥有服务接口与持久事件；**任何单一功能都不成为不可替换的 relay 内核**。

```text
DSH Web 客户端
  -> 同源 /api/chat、/api/organization 和事件流
DSH host 插件
  -> 本地 SQLite 缓存、加密媒体目录和 DSH 私人会话
  -> 向 relay 发起认证后的 HTTPS 请求和在线心跳
relay
  -> 持久化账号、组织、项目、群、队列、资源、仓库、插件、通知和分析元数据
  -> 异步处理审核、通知、Bot、扫描、仓库校验和报表任务
```

### 4.1 凭证归属硬边界

三层的凭证归属是硬边界：

| 层 | 持有 | 明确禁止 |
|---|---|---|
| 浏览器 | 仅呈现与交互状态 | **不持组织秘密、relay 凭证、设备私钥**；不能直接携带 relay access token |
| host | 本地数据库、设备凭证、relay 客户端 | **是浏览器访问组织的唯一入口** |
| relay | 组织权威数据与策略判定 | **不保存设备私钥**；不保存可直接恢复账号的明文秘密 |

Web 客户端**必须**作为 DSH client 插件实现：通过 `ctx.slots.register` 组合 UI，用已声明的 store 保存视图状态，并使用 DSH 主题 token 与 CSS Modules。

客户端**不得**向宿主页面注入未受管理的 DOM 节点，也**不得**依赖 `MutationObserver` 修复宿主重渲染。

host 路由通过 `ctx.webServer.register` 注册在 `/api/chat` 和 `/api/organization` 下，并拥有完整的请求生命周期，包括浏览器事件流。

> 三层各自的会话隔离要求，见[安全与合规 §31 标识、租户与会话隔离](../03-details/04-security-compliance.md#31-标识租户与会话隔离)。

## 5. 客户端结构与呈现约定

客户端按功能域拆分为可独立卸载的 slot 贡献：会话列表、消息视图、工作项、资源库、搜索、通知收件箱、组织与账号设置、仪表盘。每个域声明自己的 store 与路由段，卸载时释放订阅、事件流与定时器，不残留全局单例。

**视图状态与持久状态分离**：滚动位置、折叠状态、草稿编辑器焦点等属于设备本地的视图状态，放入已声明的 DSH store；消息、工作项、授权与游标属于持久状态，只能来自 host 数据库，**客户端不做权威缓存也不在浏览器中重算权限**。

> **界面显示的可用操作来自 host 返回的能力描述，而不是客户端自行推断角色。** 隐藏入口只是呈现优化，服务端仍对每次调用完整鉴权；客户端**不得**因为已隐藏入口而省略错误处理。

事件流断开、组织切换、权限修订变化和 `sync_diverged` 都是客户端**必须显式呈现**的状态，不能表现为静默停止刷新。离线时界面区分**“本地已保存待发送”“服务器已接收”和“终态失败”三种状态，绝不把未确认内容显示为已送达**。

错误呈现按错误码的可重试性分级：`retryable` 提供重试入口，`conditional` 说明需要先满足的前置条件并给出对应操作入口，`terminal` 说明原因且不提供重试按钮。客户端**不得**把 `NOT_FOUND_OR_FORBIDDEN` 渲染成“对象不存在”这类推断性描述。

大列表使用虚拟滚动与分页游标，不一次性装载整段群历史或资源目录；图片与附件按需加载并遵守下载授权，预览失败显示明确终态而不是无限加载。

> 错误码的可重试性分级定义，见[契约与规范附录 §46 错误码目录](../03-details/06-contracts-and-conventions.md#46-错误码目录)。
